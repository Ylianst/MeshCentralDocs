# MeshCentral Project Repositories

!!! info "Community-Maintained Repositories"
    Looking for community plugins, scripts, integrations, or helper projects? See the [MeshCentral Community organization on GitHub](https://github.com/orgs/meshcentral-community/repositories). These repositories are community-maintained and separate from the core MeshCentral project repositories listed below.

MeshCentral is maintained across multiple repositories. This page points to the main documentation source, the primary application repository, and closely related project repositories.

## Core Repositories

- [MeshCentralDocs](https://github.com/Ylianst/MeshCentralDocs)
  Source for this documentation site, including Markdown content, images, and navigation.

- [MeshCentral](https://github.com/Ylianst/MeshCentral)
  Main application repository for the MeshCentral server and the broader web application codebase.

## Agents and Device Components

- [MeshAgent](https://github.com/Ylianst/MeshAgent)
  Agent component used by MeshCentral-managed devices.

- [MeshCentralAndroidAgent](https://github.com/Ylianst/MeshCentralAndroidAgent)
  MeshCentral agent for Android devices.

- [MeshCentralAssistant](https://github.com/Ylianst/MeshCentralAssistant)
  Tray icon tool for the MeshCentral Agent that shows status and exposes basic controls.

## Router and Connection Tools

- [MeshCentralRouter](https://github.com/Ylianst/MeshCentralRouter)
  Standalone router and port-mapping utility for MeshCentral environments.

- [MeshCentralRouterCmd](https://github.com/Ylianst/MeshCentralRouterCmd)
  Command-line Windows variant of MeshCentral Router.

- [MeshCentralRouterMacOS](https://github.com/Ylianst/MeshCentralRouterMacOS)
  macOS port-mapping tool for MeshCentral environments.

- [MeshCentralDiscovery](https://github.com/Ylianst/MeshCentralDiscovery)
  Windows utility that scans the local network to find MeshCentral servers in LAN and Hybrid mode.

## Intel AMT and Management Tools

- [MeshCommander](https://github.com/Ylianst/MeshCommander)
  Intel AMT management tool related to the wider MeshCentral ecosystem.

- [LibMeshCtrl](https://github.com/Ylianst/LibMeshCtrl)
  Developer control module for integrating with MeshCentral.

## Installers, Sites, and Companion Services

- [MeshCentralInstaller](https://github.com/Ylianst/MeshCentralInstaller)
  Windows installer project for MeshCentral.

- [MeshCentralSatellite](https://github.com/Ylianst/MeshCentralSatellite)
  Companion tool for Active Directory computer account creation and Intel AMT certificate workflows.

- [MeshCentralSite](https://github.com/Ylianst/MeshCentralSite)
  Source for the public MeshCentral.com web site.

- [MeshCommanderSite](https://github.com/Ylianst/MeshCommanderSite)
  Source for the web site served at MeshCommander.com.

## Data and Storage

- [nedb](https://github.com/Ylianst/nedb)
  Fork of NeDB, the lightweight database used by default in many MeshCentral deployments.

## Contribution Guidance

- If you are fixing or writing documentation for this site, use [MeshCentralDocs](https://github.com/Ylianst/MeshCentralDocs).
- If you are changing server behavior, APIs, or core application functionality, use [MeshCentral](https://github.com/Ylianst/MeshCentral).
- If your change is specific to an agent or companion tool, check the related repository first.
